# Changelog

## 1.0.0-rc.1

- One cancellable background engine for refinement, answers, model discovery and real provider connection tests.
- Correct direct Anthropic model IDs and migrate legacy GitHub configuration to GitHub Models.
- Sourced model pricing, explicit unknown/custom rates, bounded output/iterations and per-run budget checks.
- Complete local session autosave, crash/restart recovery, revision history, highlighted comparison and Markdown export.
- Text-file inclusion with an explicit preview and size/encoding limits.
- Coding, investigation and general profiles that keep the original request authoritative and avoid assumed stacks.
- Updated desktop layout, keyboard shortcuts, single-instance activation and one-click restart launcher.
- Credential-redacted diagnostic logs, managed retention and atomic settings/session backups.
- Windows tests, synthetic evaluation corpus, live acceptance tools and portable artifact smoke verification.

Release-candidate status remains until the external acceptance gates in ROADMAP.md are cleared.
